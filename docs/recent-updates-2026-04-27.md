# Recent Updates (2026-04-27)

このドキュメントは、直近の仕様変更と修正内容をまとめたものです。

## UI / メニュー整理

- アプリメニューバーから `編集` を削除しました。
  - `元に戻す / やり直し / 切り取り / コピー / 貼り付け / すべて選択` のメニュー項目も削除。
- アプリメニューバーから `ウィンドウ` を削除しました。
- `表示` メニューの `全画面表示` を削除しました。
- 画面上の「選択中の PowerShell を再起動」ボタンを削除しました。
- フルスクリーン復帰用に追加していた「全画面を終了」ボタン系の制御を削除しました。

## ターミナル安定性

- xterm の描画タイミングで発生していた例外対策を追加しました。
  - `fit`, `write`, `reset` 実行時に初期化・破棄タイミングが重なっても落ちないよう防御。
  - `resize` 送信は `cols/rows > 0` のときだけ実行するよう調整。

## コマンド関連

- `dir` グループの表示名を `ディレクトリ` に変更。
- 既存設定に `dir` という古いタイトルが残っている場合も、自動で `ディレクトリ` へ移行。
- `dir` グループで重複しやすい項目を正規化する処理を維持。

## 配布 / CI

- `dist:win` を `--publish never` に変更し、ローカル配布ビルド時に意図しない publish を防止。
- GitHub Actions の release workflow を Node.js 24 系対応に更新。
  - `actions/checkout@v5`
  - `actions/setup-node@v6`
  - `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: true`
