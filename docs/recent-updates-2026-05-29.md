# Recent Updates (2026-05-29)

このドキュメントは、直近の仕様変更とリリース運用の更新内容をまとめたものです。

## 変数 / 操作シーケンス

- `{{VARIABLE_NAME}}` 形式で参照できる変数管理を追加しました。
- パスワードなどの値はシークレット変数として登録でき、Electron の `safeStorage` で暗号化してローカル保存します。
- シークレット値は renderer 側へ平文を返さず、一覧には値の有無だけを表示します。
- WSL 起動、SSH 接続、パスワード入力待ちなどの対話操作を「操作シーケンス」として登録・実行できるようにしました。
- 操作シーケンスの各ステップでは、送信前に待つ文字列、送信する文字列、送信後の待機時間、Enter 送信有無を設定できます。
- 変数管理と操作シーケンス管理は 1 つのダイアログに統合し、タブで切り替える構成にしました。

## UI / ツールバー整理

- Tips 行と Ready 表示を削除し、ツールバーを 1 本に統合しました。
- コマンドプロンプトアイコン、セッション追加、操作シーケンスをツールバー左側へ配置しました。
- 編集、履歴、設定をツールバー右側へ配置し、設定の歯車を最右端にしました。
- サイドバー切替アイコンはツールバーから削除しました。
- 設定画面では `変数 / 操作シーケンス` を `コマンド管理` より上に配置しました。
- コマンド管理は利用頻度が低い操作として、ツールバーからは外し、設定画面内の項目に整理しました。
- フォントサイズ、行間、フォント名、ターミナル色などの表示設定は、設定画面の下側へ移動しました。

## セキュリティ / 配布

- `npm audit` を実行し、開発依存の脆弱性を修正しました。
- シークレットらしき値やトークンがリポジトリ内へ混入していないことを簡易スキャンで確認しました。
- `v0.1.15` の Windows リリースを作成しました。
- Release workflow のアップロード対象を `release/latest.yml` に限定し、不要な builder debug YAML がリリースへ混入しないようにしました。

## 注意事項

- シークレット変数は保存時に暗号化されますが、送信先のプログラムが入力内容をエコー表示した場合はターミナル画面や保存した出力に残る可能性があります。
- 操作シーケンスはローカル端末内の対話操作補助です。SSH や sudo などの認証先が入力をどう扱うかは接続先の挙動に依存します。
